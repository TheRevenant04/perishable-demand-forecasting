# Example API Payloads

These JSON files are ready-to-use requests for the forecast API.

| File | Contents |
| --- | --- |
| `predict_single_request.json` | One instance, for a single prediction. |
| `predict_batch_request.json` | Five instances, for batch prediction. |

The instances are real rows from the held-out forecasting test split
(`data/processed/freshretailnet/forecasting/test.parquet`), trimmed to the 22
model features. That dataset is generated by the pipeline and is not committed;
regenerate it with:

```bash
uv run python -m perishable_demand_forecasting.data.build_daily_forecast_dataset
```

With the service running (`uv run python predict.py`):

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  --data @examples/predict_single_request.json
```

See [../docs/api.md](../docs/api.md) for the full API reference.
